# docs/archive — superseded documents (history, never truth)

Documents here are **ARCHIVE-classified**: fully superseded, kept as the historical
record. Nothing in this folder describes the current platform — do not cite an
archived document as current state. The living entry points are `HANDOFF.md`
(root) and `docs/DOCUMENTATION-INDEX.md`.

Policy (from `docs/DOCUMENTATION-GOVERNANCE.md`): we archive, we never delete.
A document moves here when every claim it makes about the present has been
superseded and no frozen document or code references its old path. Internal
links inside archived documents are frozen as-written and may point at old
paths — that is expected; consult the map below.
