# M6 sub-phase (c) — D6 strategy + D8 microcycle: design spec

**Status: DESIGN SPEC — for Simon · 2026-07-16 · no code in this doc**
**Authority: `M6-PLAN.md` §3(c) / P2-2; `02-COACHING-PIPELINE.md` §2.6 (D6) + §2.8 (D8);
EDS §20 D6/D8. The named **prerequisite for Stage-7 endurance** (10 §3; 11 §7). No new 🔒
(M6 §4: "None newly reserved"). Byte-identical for the no-fixture cohort; the ONE place M6 may
legitimately move a golden is a newly-consumed fixture signal (M6 §3(c)).**

## 0. What this builds, in one line

Turn two decisions the engine already makes *implicitly, as downstream fragments* into **typed
decision objects** — D6 `Strategy` (the develop/maintain map) and D8 `WeeklyObjective` (the
fixture-aware microcycle) — activating the richly-authored-but-dormant SKB `microcycles` section.
This is a **typing + activation**, not a new coaching decision.

## 1. D6 · `Strategy` (M-STRAT) — phase 1, byte-identical

**Today (fragment).** `blockObjective.js` already emits, per block, `developsQuality` +
`maintainsQualities` + trajectory/volumeShape/intensityShape. The macro-strategy exists but has no
single typed home (audit 03 §1's macro-strategy gap; G4).

**Build.** Compose those fragments into one typed `Strategy {value, confidence, rationale}` (EDS D6;
02 §2.6):
- `value.developMaintainMap` — per priority quality, its committed **intervention class** (e.g.
  heavy-slow resistance for tendon stiffness, eccentric protocols for hamstring robustness), so D7
  inherits a managed-concurrency plan, not a calendar template.
- `value.concurrencyModel` + `value.sequencingRules` — the interference trades, from the ratified
  EDS D6 reasoning (already implicit in how priorities are ordered + which are deferred).
- `confidence` — high where the concurrent-training evidence is L1; `rationale` — states the
  interference trades and any down-scope (Art 15 — no silent goal demotion).

**The intervention-class map is knowledge**, not code (KA Domain 6/3): a governed
`quality → intervention-class` table (new small knowledge entry, KSV bump). Where a quality's class
simply re-expresses today's implicit selection, the plan is **byte-identical**.

**Byte-identity.** D6 is a *typing of D6's ratified output* — the develop/maintain decisions are
unchanged, so every golden stays byte-identical (the Strategy object is emitted onto `meta`, read by
D7/D9 exactly as the fragments are read today). Any golden move here = a defect.

**Validation (D14 hooks).** Every `develop` entry traces to a D5 priority; every committed class
exists in Exercise/Intervention knowledge (no phantom modalities); interference pairs carry a
separation or a recorded trade.

## 2. D8 · `WeeklyObjective` (M-PERIOD microcycle) — phase 2, flag-gated

**Today (dormant).** All 11 SKB profiles carry a rich `microcycles` section (per fixture density:
`oneMatchPerWeek`, `twoMatchesPerWeek`, … — heavy/power/recovery/prevention day placement around the
match). **Nothing consumes it.** The `matches_this_week` fixture signal was deferred at M0 for
exactly this owner (M6 §3(a)).

**Build.** A typed `WeeklyObjective {value, confidence, rationale}` (EDS D8; 02 §2.8):
- `value.perDayIntent` — each day's intent **inherited from the block objective** (never a template
  label; "Monday is chest day" is the forbidden defect, Ontology §7), laid around the fixed sport
  schedule.
- `value.spacingConstraints` — sport-aware spacing (heavy far from the match, power/priming close,
  recovery after), **selected from the SKB `microcycles` pattern by fixture density**
  (`matches_this_week`).
- `value.weeklyTargets` — volume/intensity from the block trajectory (D7).
- `rationale` — how the week bends around the sport; a fixture clash ⇒ the sport wins, the gym day
  moves/lightens (Art 2); a zero-slot week ⇒ an honest zero-session week with its reason (Art 15).

**The microcycle period is a constraint-layer input, not a hard-coded seven** (01 §7): a congested
fortnight / four-day turnaround is a legitimate microcycle. The sport schedule arrives via the
constraint layer (ruling R4); in the **Team package the coach's team schedule is the authoritative
fixture input** (the Stage-5 seam).

**Byte-identity + the one legitimate golden move.**
- **Flag-gated, default-OFF** (10 §5.1). With the flag off, or for any athlete with **no fixture
  calendar**, D8 reproduces today's implicit weekly structure → **goldens byte-identical**.
- When the flag is ON **and** a fixture calendar is present, the newly-consumed `matches_this_week`
  signal legitimately reshapes the week — a **scoped re-baseline** of the fixture-bearing archetypes
  only, with an expected-delta note (this is the one place M6 may move a golden — a newly-consumed
  input, not a re-seat). No-fixture archetypes stay byte-identical.
- **Rollback** = disable the flag → no-fixture behaviour returns.

**Validation (D14 hooks).** Every per-day intent inherits from the block objective; fixed sport
sessions are immovable; the emitted spacing constraints are re-checked by D13/D14.

## 3. Build order + rules

1. **Phase 1 — D6 `Strategy`** (byte-identical): the governed intervention-class map + the typed
   Strategy object composed from the existing fragments, emitted on `meta`, consumed by D7/D9 exactly
   as today. Goldens byte-identical (KSV bump for the new knowledge entry → stamp-only). Its own PR.
2. **Phase 2 — D8 `WeeklyObjective`** (flag-gated): the microcycle consumer that activates the SKB
   `microcycles` section behind `matches_this_week`, default-OFF. No-fixture/flag-off byte-identical;
   fixture-on = scoped re-baseline. Its own PR + a fixture-bearing archetype added to the matrix.
3. **Rules:** additive-first (no new input ⇒ byte-identical); flag-gated default-OFF for the newly-
   consumed signal; every stamp-only re-baseline carries an expected-delta note; `npm test` +
   `test:engine` + `lint` green; the taper-semantics confirm from M6(a) rides here; **no 🔒**;
   **merge is Simon's.**

## 4. The endurance seam (named, not built)

D6 `Strategy` (managed concurrency) + D8 `WeeklyObjective` (fixture-aware week) are the objects a
Stage-7 endurance module hangs its aerobic sessions on — this sub-phase **builds the prerequisite,
never the endurance sessions** (🔒 10; M6 only names the seam). The concurrency model D6 emits is
exactly where the strength↔endurance interference trade will later be made.

## 5. Out of scope

Stage-7 endurance sessions; age/sex modifiers (M6 (d), 🔒 row 5); the wearable adapter (M6 (e));
the provenance-authoring sweep rows (2/8/13). D8's Team-coach fixture authoring is the Stage-5 seam
consumed here, not built here.
